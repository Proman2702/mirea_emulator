# Эмулятор оболочки ОС — вариант 14

Графический эмулятор командной строки UNIX-подобной ОС на Flutter. Виртуальная файловая система (VFS) загружается из ZIP-архива. Команды работают с ней в памяти: исходный архив не распаковывается и не изменяется. При запуске выполняется стартовый скрипт, после чего команды можно вводить в окне приложения.

## Настройка и запуск

Программа принимает два аргумента командной строки в указанном порядке:

1. Путь к ZIP-архиву VFS.
2. Путь к текстовому стартовому скрипту с одной командой на строку.

Пример запуска из корня репозитория на Windows:

```powershell
flutter pub get
flutter run -d windows -a custom/vfs.zip -a custom/script.txt
```

Каждый путь передаётся отдельным параметром `-a`. Существующий `run.bat` передаёт их одним аргументом и требует исправления; для запуска используйте команду выше.

Если путь к скрипту или архиву не существует либо ZIP не удаётся загрузить, программа выводит сообщение об ошибке и завершает работу. Пустые строки стартового скрипта пропускаются. Ошибки отдельных команд отображаются в окне, а выполнение следующих строк продолжается.

## Команды

| Команда | Действие |
| --- | --- |
| `ls` | Показать файлы и папки текущего каталога вместе с владельцами. |
| `cd <путь>` | Перейти в каталог. Поддерживаются относительные и абсолютные пути, а также отдельная команда `cd ..`. |
| `uptime` | Показать время работы оболочки. |
| `history` | Показать историю введённых команд, включая ошибочные. |
| `rm <путь>` | Удалить файл или каталог со всем содержимым из VFS в памяти. Корневой каталог удалить нельзя. |
| `chown <владелец> <путь>` | Изменить владельца файла или каталога в VFS в памяти. |
| `exit` | Закрыть приложение. |

Пути внутри VFS используют `/`; абсолютный путь начинается с `/`, например `/folder1/file3.txt`. Аргументы с пробелами можно заключать в двойные кавычки. Флаги команд не предусмотрены.

## Сборка и тесты

Команды выполняются из корня репозитория:

```powershell
flutter pub get
flutter build windows
flutter test tests
dart analyze
```

Тесты в `tests/shell_test.dart` проверяют парсер, загрузку ZIP и вложенные каталоги, основные команды, удаление, смену владельца, сообщения об ошибках и выполнение стартового скрипта.

## Примеры использования

После запуска с `custom/vfs.zip` можно ввести:

```text
ls
cd folder1/folder3
ls
cd /
chown student file1.txt
ls
rm /folder1/folder2
cd nonexistent
history
```

`cd nonexistent` показывает ошибку отсутствующего каталога. Пример `custom/script.txt` демонстрирует все команды, работу с VFS и ошибки автоматически при запуске. Изменения от `rm` и `chown` существуют только до закрытия приложения; при следующем запуске архив загружается заново.
